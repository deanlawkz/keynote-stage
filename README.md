# Keynote Stage

Кинематографичная 3D-среда для презентаций: слайды висят в тёмном пространстве, камера пролетает сквозь них.

## Запуск

```bash
pnpm install
pnpm dev          # http://localhost:3300
```

Сценарий по умолчанию — `public/scenarios/demo.json`. Другой: `http://localhost:3300/?s=имя` → `public/scenarios/имя.json`.

Управление: `→` / пробел / `PgDn` — вперёд, `←` / `PgUp` — назад, `Home` / `End`, `F` — полный экран, клик по правой части экрана — вперёд, по левой — назад.

## Сценарий

```json
{
  "title": "Название",
  "accent": "#5aa9ff",
  "slides": [
    { "layout": "title",   "kicker": "надпись сверху", "title": "Заголовок", "subtitle": "Подзаголовок" },
    { "layout": "section", "kicker": "01", "title": "Раздел", "subtitle": "Пояснение" },
    { "layout": "bullets", "kicker": "тема", "title": "Заголовок", "bullets": ["пункт", "пункт"] },
    { "layout": "stat",    "title": "Заголовок", "stats": [{ "value": "151", "label": "подпись" }] },
    { "layout": "media",   "title": "Заголовок", "image": "/media/файл.png", "caption": "подпись" },
    { "layout": "quote",   "quote": "Цитата", "author": "Автор" }
  ]
}
```

- `accent` можно задать и в отдельном слайде.
- Скриншоты и фото: `"image": "/media/x.png"` — одна картинка, `"images": ["…", "…"]` — карусель.
  Картинки живут в 3D перед слайдом; камера подлетает к ним ближе. Свайп двумя пальцами / пальцем /
  перетаскиванием мышью листает (один шаг на жест), колёсико или щипок — зум с подлётом камеры.
  Точки под каруселью показывают активную картинку и кликабельны.
- Картинки кладутся в `public/media/`.

## Сборка для GitHub Pages


## Страховка от чужих компьютеров

Сборка самодостаточна: шрифт Inter, все библиотеки и сценарии вшиты — ничего не берётся с компьютера докладчика и из сети.

| Что может сломаться в зале | Что сделано |
|---|---|
| Нет интернета / Wi-Fi конференции не пускает на github.io | Сценарии вшиты в сборку; после первого открытия с сетью сайт кэшируется и работает офлайн (service worker) |
| Нет видеокарты, WebGL запрещён политикой, удалённый рабочий стол, старый ноутбук | Автоматический **плоский 2D-режим** (те же слайды, кроссфейд). Принудительно: `?flat=1` |
| Windows/Chrome молча рисует без ускорения (рваная анимация) | Предупреждение с инструкцией, где включить аппаратное ускорение |
| Слабая видеокарта, кадров мало | Автоснижение качества: < 40 fps → разрешение 1×, без сглаживания; всё ещё мало → без постобработки |
| Windows «Уменьшить анимацию» / prefers-reduced-motion | Игнорируется — код от него не зависит |
| Экран гаснет, заставка во время доклада | Wake Lock — экран не засыпает, пока открыта презентация |
| Нет шрифтов | Inter (латиница + кириллица) вшит в сборку, канвас использует его же |
| Пульт-кликер | PageUp/PageDown, `B` и `.` — чёрный экран, `F` — полный экран |
| Совсем ничего не работает | **Shift+R** — запись всей презентации в видеофайл `.webm` (прогон всех сцен, `?hold=5` — секунд на сцену). Видео откроется где угодно (Chrome, Edge, VLC). `ffmpeg -i файл.webm -c:v libx264 -pix_fmt yuv420p файл.mp4` — если нужен MP4 для PowerPoint |

Самый надёжный вариант для важного выступления: свой ноутбук + видеофайл на флешке как запасной.
