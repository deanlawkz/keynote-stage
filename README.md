# Keynote Stage

Базовый набор для кинематографичных 3D-презентаций: чёрное пространство, слайды — светящиеся панели,
камера пролетает сквозь них. Контент — один JSON-файл, всё остальное уже сделано.

**Для ИИ-агента:** начни с [CLAUDE.md](CLAUDE.md) — там правила работы с этой основой.

- Формат сценария — [docs/SCENARIO.md](docs/SCENARIO.md)
- Публикация, офлайн, видеофайл — [docs/DEPLOY.md](docs/DEPLOY.md)
- Демо: `public/scenarios/demo.json` (по одной сцене каждого типа)

```bash
pnpm install
pnpm dev          # http://localhost:3300/?s=demo
```

Управление: `→`/`←`, пробел, PgUp/PgDn, клик; `F` — полный экран; `B` — чёрный экран; `Shift+R` — видеофайл.
На слайде с картинками: свайп — листать, колёсико/щипок — зум.

## Что защищено от чужих компьютеров

| Проблема в зале | Решение в основе |
|---|---|
| Нет интернета / Wi-Fi блокирует сайт | Сценарии вшиты в сборку, service worker кэширует сайт после первого открытия |
| Нет видеокарты, WebGL запрещён, удалённый стол | Автоматический плоский 2D-режим (`?flat=1` принудительно) |
| Слабая видеокарта | Автоснижение качества при < 40 fps |
| Windows рисует без ускорения | Предупреждение с инструкцией |
| «Уменьшить анимацию» в системе | Игнорируется |
| Экран гаснет | Wake Lock |
| Любые пропорции экрана (4:3 … 32:9) | Камера сама вписывает слайд в кадр |
| Нет шрифтов | Inter вшит в сборку |
| Всё сломалось | `Shift+R` — видеофайл презентации, играет где угодно |
