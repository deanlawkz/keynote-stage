# Keynote Stage — базовый набор для 3D-презентаций

> Инструкция для ИИ-агента (Claude, GPT, любой). Прочитай целиком перед работой.

## Что это

Готовое трёхмерное пространство для презентаций: чёрный космос, слайды — светящиеся панели, камера
пролетает сквозь них. Контент презентации — **один JSON-файл**. Стек: Next.js 16 + react-three-fiber.

## Главное правило

**Этот репозиторий — неизменяемая основа.** Пространство, камера, свет, жесты, навигация, постобработка,
защита от слабых компьютеров — всё это принято владельцем и **не переделывается** при сборке новой презентации.

Новая презентация = новый сценарий + свои картинки. Ничего больше.

| Можно менять | Нельзя менять (без прямой просьбы владельца) |
|---|---|
| `public/scenarios/*.json` — сценарии | `src/components/stage/**` — 3D-пространство, камера, карусель |
| `public/media/**` — картинки | `src/lib/**` кроме `scenario.ts` типов — жесты, раскладка, painter |
| `src/generated/` (генерируется сам) | `src/components/ui/**` — HUD, навигация, плоский режим |
| README проекта-потомка | `src/app/**`, конфиги, зависимости |

Если для контента нужен новый тип слайда — сначала предложи владельцу, не добавляй молча.

## Как собрать новую презентацию (пошагово)

1. `pnpm install` (Node 20+, pnpm).
2. Создай `public/scenarios/<имя>.json` по формату из [docs/SCENARIO.md](docs/SCENARIO.md).
   Картинки положи в `public/media/`, пути в JSON — `/media/файл.png`.
3. `pnpm dev` → http://localhost:3300/?s=<имя>. Проверь каждую сцену.
4. Публикация: [docs/DEPLOY.md](docs/DEPLOY.md) (GitHub Pages одной командой, офлайн-режим, видеофайл).

## Что уже умеет основа (не дублируй)

- Типы слайдов: `title`, `section`, `bullets`, `stat`, `media` (одна картинка или карусель), `quote`.
- Картинки: 3D-карусель, свайп = один шаг, колёсико/щипок = зум с подлётом камеры, точки-индикатор.
- Навигация: `←`/`→`, пробел, PgUp/PgDn, Home/End, клик (правая/левая часть экрана),
  вертикальная линия с точками-сценами справа, `F` — полный экран, `B`/`.` — чёрный экран.
- Адаптация к любому экрану: камера сама отходит так, чтобы слайд целиком был в кадре (4:3 … 32:9).
- Слабый компьютер: автоснижение качества при < 40 fps; без WebGL — плоский 2D-режим (`?flat=1`).
- Без интернета: сценарии вшиты в сборку, service worker кэширует сайт.
- `Shift+R` — экспорт всей презентации в видеофайл `.webm` (`?hold=N` — секунд на сцену).
- Экран не гаснет (Wake Lock). Шрифт Inter (латиница + кириллица) вшит.

## Вкусовые требования владельца (соблюдать в контенте)

- Ничего мерцающего, никаких ярких вспышек и пульсаций.
- Картинки не должны быть засвечены; скриншоты — читаемыми (карусель подлетает сама).
- Текст крупный, коротко, один смысл на слайд. Длинные списки дели на несколько сцен.
- Заголовки сцен короткие: они видны в навигации и в экспорте.

## Проверка перед сдачей

- Все сцены открываются, текст не обрезан, картинки читаемы.
- `pnpm build` проходит без ошибок (сценарии вшиваются автоматически через `prebuild`).
- В консоли браузера нет ошибок.
