# Формат сценария

Файл: `public/scenarios/<имя>.json`. Открывается по адресу `/?s=<имя>` (по умолчанию `demo`).

```json
{
  "title": "Название презентации",
  "accent": "#5aa9ff",
  "slides": [ ... ]
}
```

- `title` — имя файла при экспорте видео.
- `accent` — цвет акцента (буллеты, цифры, подписи). Можно переопределить в любом слайде полем `accent`.

## Типы слайдов

### `title` — титул
```json
{ "layout": "title", "kicker": "надпись мелко сверху", "title": "Заголовок", "subtitle": "Подзаголовок" }
```

### `section` — раздел
```json
{ "layout": "section", "kicker": "01", "title": "Название раздела", "subtitle": "Пояснение в одну строку" }
```

### `bullets` — список
```json
{ "layout": "bullets", "kicker": "тема", "title": "Заголовок", "bullets": ["тезис", "тезис", "тезис"] }
```
До 4–5 пунктов, каждый не длиннее двух строк. Больше — делите на две сцены.

### `stat` — цифры
```json
{ "layout": "stat", "title": "Заголовок", "stats": [
  { "value": "151", "label": "подпись" },
  { "value": "7", "label": "подпись" },
  { "value": "100%", "label": "подпись" }
] }
```
От 1 до 4 показателей. Значение — коротко (число, процент, «×3»).

### `media` — картинка или карусель
```json
{ "layout": "media", "title": "Заголовок", "image": "/media/один.png", "caption": "подпись" }
{ "layout": "media", "title": "Заголовок", "images": ["/media/a.png", "/media/b.png", "/media/c.png"] }
```
Картинки — PNG/JPG в `public/media/`, до ~2 МБ каждая, ширина 1200–2000 px. Карусель: свайп листает,
колёсико/щипок — зум. Первая картинка активна при входе на сцену.

### `quote` — цитата
```json
{ "layout": "quote", "quote": "Одна мысль на весь экран.", "author": "Автор" }
```

## Ограничения текста

Панель слайда широкая (2.9:1). Длинный текст переносится сам, но:
- заголовок `title` — до ~40 символов; титул — до ~25;
- пункт списка — до ~90 символов;
- цитата — до ~160 символов.
