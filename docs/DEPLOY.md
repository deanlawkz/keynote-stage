# Публикация и запуск в зале

## Локально
```bash
pnpm install
pnpm dev            # http://localhost:3300/?s=имя
```

## GitHub Pages (постоянный адрес)
В репозитории уже есть workflow `.github/workflows/pages.yml`: любой push в `main` собирает сайт и публикует
на `https://<owner>.github.io/<repo>/`. Один раз включить Pages: Settings → Pages → Source: **GitHub Actions**.

Для форка/копии под новую презентацию — просто push. Адрес сценария: `https://<owner>.github.io/<repo>/?s=имя`.

## Своя сборка
```bash
BASE_PATH=/имя-репозитория pnpm build   # статика в out/
```
`out/` можно отдать любым статическим хостингом или `npx serve out` с флешки.

## В зале
- Открыть адрес заранее с интернетом — после этого сайт работает офлайн (кэш).
- `F` — полный экран. Пульт: PageUp/PageDown. `B` — чёрный экран.
- Если компьютер слабый — качество снизится само; если WebGL запрещён — включится плоский режим.
  Принудительно плоский: добавить `?flat=1` к адресу.
- Запасной вариант: `Shift+R` записывает видеофайл всей презентации (`?hold=5` — секунд на сцену).
  MP4 для PowerPoint: `ffmpeg -i файл.webm -c:v libx264 -pix_fmt yuv420p файл.mp4`.
